# Koru Garden - Bursa Kır Düğünü & Özel Davet Bahçesi Website

Bu proje, Bursa Osmangazi Çeltikköy'de yer alan **Koru Garden** mekanı için tasarlanmış modern, ışıltılı beyaz zeminli, orman yeşili ve ahşap tonları ile bezeli duyarlı (responsive) web sitesidir.

## 🚀 Proje Yapısı

- `index.html` -> Anasayfa (Hero, Ayrıcalıklar, SEO Metinleri, Konseptler)
- `hakkimizda.html` -> Hakkımızda (Mekan Hikayesi, Detaylı Özellikler Tablosu)
- `iletisim.html` -> İletişim (Adres, Tel, WhatsApp Hattı, Müsaitlik Formu, Google Maps)
- `style.css` -> Projenin tüm stil ve renk paletini içeren modern CSS dosyası

## 🌐 GitHub Pages İle Yayınlama Adımları

1. Bu depoyu (repository) GitHub hesabınıza yükleyin/push yapın.
2. GitHub'da deponuzun **Settings (Ayarlar)** sekmesine gidin.
3. Sol menüden **Pages** seçeneğine tıklayın.
4. **Build and deployment** başlığı altındaki **Branch** seçeneğini `main` (veya `master`) olarak seçip **Save** butonuna basın.
5. Birkaç dakika içinde web siteniz `https://kullaniciadi.github.io/depo-adi/` adresinde yayında olacaktır!
